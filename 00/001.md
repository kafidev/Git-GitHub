
1. Isku-xirka: Frontend ──( API )──> Backend
Sida aad si sax ah u sheegtay, API (Application Programming Interface) waa buundada isku xirta Frontend-ka iyo Backend-ka.

Waa maxay shaqadiisu? Wuxuu u oggolaadaa laba software oo ku kala yaalla meelo kala duwan (ama ku qoran luuqado kala duwan) inay wada hadlaan.

Tusaale: Marka uu isticmaalahu (User) ku dhufto badhanka "I bixi dalabka" ee ku yaalla Frontend-ka (Client App/Web), Frontend-ku wuxuu API u soo diraa codsi (Request) ah: "Fadlan ninkan dalabkiisa ii diwaangeli."

Sida aad sheegtay: API-gu wuxuu isku xiri karaa websaydh caadi ah, app-ka moobilka, ama xitaa laba system oo gebi ahaanba kala madax-bannaan.

2. Isku-xirka: Backend ──( PRISMA )──> Database
Halkan ayaa ah meesha Prisma ay ka shaqayso. Prisma waxay ku dhex nooshahay dhexda Backend-ka, waxayna shaqadeedu tahay inay Backend-ka ku xirto Database-ka.

+-------------------------------------------------------+
|                      BACKEND                          |
|                                                       |
|   [ API Route / Endpoint ]                            |
|             │                                         |
|             ▼                                         |
|      [ Prisma Client ]                                |
|             │                                         |
+-------------┼-----------------------------------------+
              │  (Prisma waxay koodkaaga u rogtaa SQL)
              ▼
        [ Database ] (Sida PostgreSQL ama MySQL)

        Shaqada Prisma: Marka uu Backend-kaagu ka helo codsigaas API-ga ee Frontend-ka ka yimid, backend-ku wuxuu u baahanyahay inuu xogtaas ku kaydiyo Database-ka. Halkii uu Backend-ku si toos ah u qori lahaa luuqada SQL ee adag, wuxuu u yeeraa Prisma. Prisma ayaa koodkii JavaScript/TypeScript ee fududaa u beddesha SQL, kuna shubta database-ka dhexdiisa.

        Marka la isku wada daro (The Flow):
User-ka wuxuu taabtaa screen-ka (Frontend).

Frontend-ka wuxuu wacdaa API-ga si uu ula hadlo Backend-ka.

Backend-ka wuxuu isticmaalaa Prisma si uu xogta u geliyo ama uga soo bixiyo Database-ka.

Prisma waxay jawaabta u soo celisaa Backend-ka, Backend-kana wuxuu u soo celshaa Frontend-ka isagoo soo marinaya API-gii.
